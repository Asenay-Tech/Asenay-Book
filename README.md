# Asenay-Book

AI bookkeeping engine that automates 98-100% of financial tasks—uploads, OCR, categorization, fraud check.

## About

Asenay-Book is an intelligent bookkeeping solution that leverages AI to streamline and automate financial operations. The platform handles document uploads, performs optical character recognition (OCR), automatically categorizes transactions, and includes fraud detection capabilities.

## Features

- 📄 **Automated Document Upload**: Seamless document ingestion
- 🔍 **OCR Technology**: Extract data from financial documents
- 🏷️ **Smart Categorization**: AI-powered transaction classification
- 🛡️ **Fraud Detection**: Built-in fraud checking mechanisms
- ⚡ **High Automation**: 98-100% automation of routine financial tasks

## Tech Stack

- Next.js
- Supabase
